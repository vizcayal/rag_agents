Knowledge Base
Bedrock KB + S3

El usuario hace una pregunta en la UI de Streamlit (corriendo en ECS). La UI llama al AgentCore Runtime via boto3. El Runtime ejecuta el pipeline LangGraph que recupera chunks de la Knowledge Base, razona con Nova Lite, y valida la respuesta antes de devolverla.

🔗

Pipeline del Agente (LangGraph StateGraph)

1

Retriever

Busca los chunks más relevantes en Bedrock Knowledge Bases usando búsqueda vectorial

retriever.py
2

Reasoner

Envía los chunks + pregunta a Amazon Nova Lite. Genera respuesta con chain-of-thought en JSON

reasoner.py
3

Validator

Verifica que las citas existan en el contexto. Detecta alucinaciones y asigna confianza

validator.py

Estado compartido (AgentState): query → retrieved_chunks → reasoner_output → validator_output → respuesta final con confianza

Flujo de Deploy de la UI

1

Build — Construir imagen Docker localmente

Empaqueta el código de Streamlit + dependencias en una imagen

docker build -t rag-agent-ui .
2

Login — Autenticarse en ECR

Obtiene credenciales temporales de AWS para subir imágenes

aws ecr get-login-password | docker login
3

Push — Subir imagen a ECR

Tag con la URL del repositorio y sube la imagen

docker push 911268715109.dkr.ecr...
4

Deploy — Forzar nuevo despliegue en ECS

ECS detiene el contenedor viejo y levanta uno nuevo con la imagen actualizada

aws ecs update-service --force-new-deployment

Resumen de Servicios AWS

🐳

ECR — Elastic Container Registry

Almacena imágenes Docker privadas. Cada push sube una nueva versión de tu app.

⚙️

ECS — Elastic Container Service

Orquesta contenedores Docker. Fargate elimina la necesidad de gestionar servidores.

⚡

Bedrock AgentCore Runtime

Ejecuta agentes de IA en modo serverless. Express mode para baja latencia.

📚

Bedrock Knowledge Bases

RAG gestionado: indexa documentos en S3 y expone búsqueda vectorial con una API.

🧠

Amazon Nova Lite

LLM de AWS optimizado para velocidad y costo. Accedido via Bedrock Runtime converse API.

🔐

IAM — Identity and Access Management

Controla qué servicios pueden hablar con cuáles. El agente usa un rol con permisos mínimos.

Lo que construiste

🤖 Agente RAG

  • Pipeline LangGraph con 3 nodos (Retrieve → Reason → Validate)
  • Búsqueda vectorial sobre documentos del EU AI Act
  • Razonamiento con chain-of-thought y citación de fuentes
  • Validación anti-alucinaciones con score de confianza

☁️ Infraestructura AWS

  • Agente serverless en Bedrock AgentCore (Express mode)
  • UI containerizada en ECS Fargate
  • Imágenes Docker versionadas en ECR
  • Deploy reproducible con 4 comandos AWS CLI

🎨 UI Streamlit

  • Chat con historial de conversación
  • Muestra citas de los documentos fuente
  • Se comunica con AgentCore via boto3 EventStream
  • Health check integrado para ECS

📐 Buenas prácticas

  • Imports lazy para inicialización rápida (<30s)
  • Degradación graceful si MCP validator no disponible
  • Variables de entorno para config (ARN, región)
  • Separación de responsabilidades por archivo
